# Knowledge Base Articles

## Slow PC
1. Restart the computer.
2. Check Task Manager for unusually high CPU/memory usage.
3. Confirm sufficient disk space.
4. Check pending OS/application updates.
5. Document findings in the incident.
6. Escalate if hardware diagnostics indicate a fault.

## Wi-Fi Not Connecting
1. Confirm Wi-Fi is enabled.
2. Forget and reconnect to the network.
3. Check whether other devices can connect.
4. Restart the network adapter.
5. Verify IP configuration.
6. Escalate to Network Support when the issue is infrastructure-related.

## Printer Offline
1. Check power and physical connections.
2. Confirm the correct printer is selected.
3. Clear stuck print jobs.
4. Restart the print spooler if required.
5. Test a print job.
6. Escalate hardware/network faults when necessary.
